# Sim Kart Takip Uygulaması (SIM Card Tracking Application)

This is a desktop application designed to manage and track SIM card inventory. It helps users keep records of SIM card details, their status, ownership, and network history.

## Main Features

*   Query existing SIM card details.
*   Add new SIM card records.
*   List all registered SIM cards with options to view details or delete.
*   Define and update usage periods (start and end dates).
*   Change network provider and track network history.
*   Define and update the physical status of SIM cards (e.g., with customer, in shop).
*   List SIM cards that are available for sale.
*   User-friendly GUI.

## Technologies Used

*   Programming Language: Python
*   GUI: Tkinter
*   Database: SQLite
*   Calendar Widget: tkcalendar

## Project Structure

*   **`sim.py`**: The main Python script containing the application's logic and GUI implementation using Tkinter.
*   **`exe file/`**: This directory contains:
    *   `dist/sim.exe`: A standalone Windows executable of the application, packaged using PyInstaller.
    *   `dist/sim_kart_takip.db`: The SQLite database file used by the application. (Note: It's usually better to have the database in a user-writable location, but we're documenting the current structure).
    *   `sim.spec`: The PyInstaller spec file used to build the executable.
    *   `build/`: Intermediate build files generated by PyInstaller.

## Installation and Usage

### Running the Executable
*   Navigate to the `exe file/dist/` directory.
*   Run `sim.exe`.
*   The application will use the `sim_kart_takip.db` database file located in the same directory.

### Running from Source (Optional)
*   **Prerequisites:**
    *   Python 3.x
    *   Tkinter (usually included with Python)
    *   tkcalendar: Install using pip: `pip install tkcalendar`
*   **Running the application:**
    *   Ensure the `sim_kart_takip.db` file is in the same directory as `sim.py`, or modify the script to connect to the database at `exe file/dist/sim_kart_takip.db`.
    *   Open a terminal or command prompt.
    *   Navigate to the project's root directory.
    *   Run the script: `python sim.py`
*   **Note on Database Location when running from source:** The script `sim.py` currently connects to `sim_kart_takip.db` assuming it's in the same directory as the script. If you run `sim.py` from the root, you'll need to either:
    *   Copy `exe file/dist/sim_kart_takip.db` to the root directory.
    *   Or, modify the `sqlite3.connect('sim_kart_takip.db')` line in `sim.py` to point to the correct path (e.g., `sqlite3.connect('exe file/dist/sim_kart_takip.db')`).

## Database Information

*   **Database File:** `sim_kart_takip.db`
*   **Location:**
    *   When running the executable: Located in `exe file/dist/`.
    *   When running from source: The script `sim.py` expects it in the same directory as the script by default. (Refer to "Installation and Usage" for notes on path adjustment).
*   **Table Name:** `numaralar`
*   **Table Schema:**
    *   `numara` (TEXT, PRIMARY KEY): The phone number.
    *   `hat_sahibi` (TEXT): The owner of the SIM card.
    *   `mevcut_sebeke` (TEXT): The current network provider.
    *   `son_kullanim_baslangic` (TEXT): Start date of the last usage period (YYYY-MM-DD).
    *   `son_kullanim_bitis` (TEXT): End date of the last usage period (YYYY-MM-DD).
    *   `durum` (TEXT): The status of the SIM card (e.g., "Satılabilir", "Müşteride", "Dükkanda", "Geçiş Yapılacak").
    *   `son_gecis_tarihi` (TEXT): The date of the last network change (DD.MM.YYYY).
    *   `gecmis_sebeke` (TEXT): The previous network provider.
